Tous les textes dans le SaaS doivent avoir les accents francais corrects : e, e, e, a, u, c, o, i, etc.

**Why:** L'app est en francais pour des clients francophones. Des textes sans accents font cheap et non professionnel. Jonathan l'a signale comme un probleme global sur toute l'app.

**How to apply:** A chaque creation ou modification de page, verifier que tous les textes affiche ont leurs accents. Inclut les titres, boutons, placeholders, labels, messages d'erreur, status messages. C'est un bug global a corriger sur tout le SaaS.
