Le module principal s'appelle **Brand OS**. Pas "Brand OS Story".

"Story" (Ton histoire) est le module 01 sur 12 à l'intérieur du Brand OS. Quand Jonathan dit "on attaque le Brand OS", il parle de l'ensemble des 12 modules, pas du module Story spécifiquement.

**Why:** J'ai commis l'erreur de dire "Brand OS Story" comme si c'était le nom du produit. Jonathan a corrigé le 2026-04-10.

**How to apply:** Utiliser "Brand OS" pour parler du module entier. Si on parle d'un module spécifique, dire "Brand OS, module Story" ou "Brand OS, module Audience", etc.
