Les libellés de boutons d'action doivent être courts. Ne jamais écrire "Affiner cette slide" ni "Affiner cette section" : juste **"Affiner"**. Pareil pour les autres actions, garder le verbe seul quand le contexte est clair.

**Why:** "Affiner cette slide" est trop long, ça alourdit l'UI. Cohérent avec [[feedback_less_is_more_premium]].

**How to apply:** Dans les éditeurs (script, carousel, story), boutons d'action = verbe court. Voir aussi les vrais libellés du code : carousel utilise Développer / Condenser / Optimiser, pas "Affiner".
