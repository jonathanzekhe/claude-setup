Quand je partage une URL (mockup, page live, preview vividflow.co / Brvndlab), la donner en **lien Markdown cliquable** `[texte](https://...)`, jamais en texte brut à copier-coller.

**Pourquoi** : Jonathan ouvre les liens directement depuis le terminal/IDE ; le texte brut l'oblige à sélectionner + copier + coller à chaque fois, c'est pénible.

**Comment l'appliquer** : chaque fois que je livre un mockup ou une URL live, format `[vividflow.co/xxx.html](https://vividflow.co/xxx.html)`. Complète [[feedback_always_link_preview_url]] (lien preview en tête) et [[feedback_open_in_chrome]].
