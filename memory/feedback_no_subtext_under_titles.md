Dans toute l'interface Brvndlab, ne JAMAIS mettre de sous-texte explicatif sous les titres de section ou de page. Les gens comprennent le titre. Le sous-texte = bruit visuel et surcharge cognitive.

Exemples à SUPPRIMER systématiquement :
- "Tes contenus Instagram" → "Clique sur un post pour voir ses analytics" ❌
- "Thumbnails gagnantes" → "Filtre par type pour t'inspirer selon ta propre DA" ❌
- "Transcript reformaté" → "Traduit et structuré par l'IA en hooks + points clés" ❌
- "Patterns visuels sur ce sujet" → "Ce qui revient systématiquement dans les thumbnails qui cartonnent" ❌

**Why:** Jonathan trouve que les sous-titres surchargent les écrans et n'apportent aucune valeur réelle. Les utilisateurs comprennent avec le titre, les éléments visuels font le reste du travail. Cette règle s'inscrit dans "Less is more sur écrans premium" et "Esthétique old money premium".

**How to apply:**
- Sur chaque titre de section, titre de page, titre de card : titre seul, point.
- EXCEPTION UNIQUE : les boutons d'action peuvent avoir une description courte qui CLARIFIE l'action ("Lancer la recherche" + "scan FR + EN en 90s"). Sous-texte = trigger d'action, jamais décoration.
- Quand on est tenté d'ajouter un sous-texte, supprimer. Si vraiment besoin d'info, la mettre en tooltip au hover, jamais en visible permanent.
- Vérifier tous les mockups existants pour retirer les sous-textes déjà présents.
