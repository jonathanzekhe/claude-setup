Le skill [[brainstorm-loop]] est la manière de travailler par défaut de Jonathan, validée le 2026-07-20. Il fusionne deux skills en un seul mouvement : le brainstorm profond (décider par petits pas, sceller chaque décision, format de clarté) puis la boucle corrective (agents, superviseur qui remesure, critère d'arrêt).

**Why:** Jonathan a explicitement demandé d'assembler sa façon de brainstormer décision par décision avec loop-corrective, en une seule méthode qui va du premier doute jusqu'au code vérifié.

**How to apply:** l'utiliser pour toute session de fond (réflexion + exécution). Règle d'or : à chaque point brainstormé, on pousse et on vérifie derrière que c'est bien fait, PUIS chantier suivant. Un chantier à la fois, fini et vérifié avant d'avancer. Fichier local : ~/.claude/skills/brainstorm-loop/SKILL.md. À pousser sur le GitHub des skills quand le repo est confirmé (dossier ~/.claude/skills n'est pas un repo git en local). Voir [[feedback_brainstorm_format_clarte]].
