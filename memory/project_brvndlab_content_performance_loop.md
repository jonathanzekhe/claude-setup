## À installer en temps voulu, pas maintenant

Jonathan veut qu'on se souvienne qu'il faut mettre en place un système basé sur le contenu/script qui :

1. Détecte via API sociale (YouTube, Instagram, TikTok) qu'un contenu a été posté
2. Matche le contenu publié avec son script/story/carrousel d'origine dans Brvndlab
3. Récupère les stats de performance (vues, likes, partages, watch time, rétention)
4. Génère des insights IA sur ce qui performe (par format, funnel, angle, hook)
5. Retourne la boucle dans le module Contenu : "Ton angle X performe 3x mieux", "Les BOFU convertissent 2x plus que les MOFU"

**Why:** fermer la boucle création → performance, nourrir le Brand OS en data réelle, permettre aux clients d'apprendre de leurs propres contenus plutôt que de deviner.

**How to apply:** ne rien coder maintenant. Le rappeler quand les connexions sociales (YouTube OAuth, Apify IG/TT) seront en place et qu'il y aura assez de contenus publiés pour que l'analyse ait du sens. Tracé dans suivi.html section rose "Tracking performance contenu".
