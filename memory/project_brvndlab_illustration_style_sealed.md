**STYLE = GRAVURE ANCIENNE MONOCHROME (toile de Jouy / planche scientifique / Gustave Doré).**
- Trait fin, hachures + pointillé denses, ultra détaillé. "Tout est dans les détails."
- **Encre crème-or sur fond noir profond** (à confirmer définitivement : crème/blanc chaud vs bleu sur crème vs encre signature émeraude/or — direction actuelle = crème-or sur noir).
- Monochrome → règle la question couleur + s'intègre à l'UI sombre. L'encre peut devenir la couleur de marque.
- Univers = **jardin/scène classique** (urnes, topiaires, cyprès) avec **l'IA tissée dedans** = "le meilleur de l'humain × la puissance de l'IA".
- Cohérent PAR NATURE (une encre, une technique = série automatique). Référence validée par Jonathan : **Nous Research / Hermes (portal.nousresearch.com)** qui a bâti son identité d'IA sur la gravure.
