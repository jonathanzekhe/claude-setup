## Format Q&A - Validé le 12 avril 2026

4ème type de contenu à côté de "J'ai une idée", "Inspiration", "Ma vidéo".

**Concept** : Un vidéographe filme le créateur et lui pose des questions. Les réponses naturelles deviennent du contenu.

**Flow** :
1. Le client choisit "Session Q&A"
2. Il choisit un thème (libre ou basé sur le Brand OS)
3. Il choisit le nombre de questions (3, 5, ou 7)
4. L'IA génère les questions, chacune taguée TOFU/MOFU/BOFU automatiquement selon la profondeur
5. Le client valide/modifie les questions
6. Il partage avec son vidéographe
7. Après tournage, chaque réponse = un contenu dans le pipeline

**Règles** :
- Le funnel (TOFU/MOFU/BOFU) est déterminé AVANT le tournage, basé sur le type de question
- Pas de script, c'est naturel
- TOFU = questions larges, accessibles
- MOFU = questions qui creusent
- BOFU = questions transformation/résultats
- Fonctionne avec ou sans Brand OS (si sans, le client donne un thème manuellement)

**Why:** Jonathan trouve le format Q&A très naturel, sans script, authentique. Les réponses face caméra à des questions profondes créent du contenu engageant.

**How to apply:** Implémenter comme 4ème carte sur la page Contenu. À faire après validation complète de la section Contenu actuelle.
