## Flow validé (5 étapes)

1. **Récap accomplissements** (dark bento card sur EEF0F4)
   - Kicker "Avant de partir"
   - Grille 3×2 : Vues, CA attribué (champagne), Leads, Contenus, Brand OS, Temps économisé
   - Question "Êtes-vous sûr..." + 2 CTAs
2. **Offre -25%** (card blanche, remise élégante, prix barré → nouveau)
3. **Offre -40%** (dernière chance, même style)
4. **Ask-the-why** (6 raisons cliquables + textarea optionnelle)
5. **Confirmation** (info dates + réactivation 1 clic)

## Chemin alternatif

Si user accepte la remise à n'importe quel moment → écran "Remise appliquée" vert avec récap prélèvement.

## Règles design appliquées (pour cohérence Brvndlab)

- Fond unique #EEF0F4 + dots sur tous les écrans
- Hero dark contenu dans une bento card (pas full screen)
- Cards blanches rounded 28px pour le reste
- Accent champagne/amber (pas orange criard) pour le CA attribué
- Discount présenté élégamment : prix barré → nouveau prix + petit badge
- Zéro emoji

## Interactivité

- Navigation démo en bas (5 boutons)
- Reasons cliquables avec état "selected"
- Textarea éditable
- Tous les CTAs naviguent entre écrans
