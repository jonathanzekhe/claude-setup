Dans Brvndlab, la notion de **thumbnail** (miniature visuelle) s'applique **uniquement aux vidéos long format YouTube**. Jamais pour les shorts, reels Instagram, ou TikToks.

**Why:** Les formats courts s'affichent avec la première frame automatiquement sur leurs plateformes. Créer une miniature dédiée n'a pas d'intérêt, contrairement au long format YouTube où le thumbnail est un des leviers majeurs du CTR.

**How to apply:**

1. Dans le Miniamaker dashboard, les tâches "Thumbnail" doivent **toujours** référencer une vidéo long format YouTube. Jamais un short ou un reel.

2. Dans la vue Contenu / Pipeline éditorial, seuls les contenus au format long YouTube ont un slot "thumbnail à produire" dans leur checklist.

3. Dans la galerie Thumbnails gagnantes de Research, tout vient de YouTube long format (cohérent avec le fait que Research = YouTube uniquement).

4. Si un Clipeur produit un short à partir d'un long format YouTube, **le Clipeur ne produit pas de thumbnail** pour ce short. Il livre juste la vidéo découpée.

5. Le rôle Miniamaker reste défini par :
   - Thumbnails long format YouTube
   - Assistance production (planning, dossiers prod, etc.)
   - Autres tâches ponctuelles confiées par l'utilisateur

Plus de confusion possible : format court → pas de thumbnail à produire.
