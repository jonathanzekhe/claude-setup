Hub de références de scraping : **scraping-refs.vercel.app** (un seul Vercel, alias stable, ne change jamais). Repo local `~/dev/scraping-refs`, statique pur (pas de framework). Routes internes = dossiers `pages/<section>/<slug>/index.html`. Hub = `index.html` avec 3 sections (secteur/entreprise/usage), 15 cartes ; `READY` Set active une carte quand la page est scrapée. Ajouter une page = coder sa route + `vercel deploy --prod --yes` (même projet, URL identique).

**Workflow scraping une page Neocell :**
1. Playwright navigate + `document.documentElement.outerHTML` (evaluate, sauve fichier). Le HTML sort en string JSON échappée → `JSON.parse`.
2. Build : inline le CSS Tailwind (`curl neocell.ai/css/tailwind.min.css`), retirer tous les `<script>`/`<noscript>`, remplacer `<link tailwind>` par `<style>` inliné. Ajouter barre `← Références` (lien vers `/`) fixée en haut à gauche.
3. Trim via `~/dev/scraping-refs/trim-page.js`.

**RÈGLE DE TRIM (scellée par Jonathan, ne plus jamais se tromper) :**
On garde **uniquement ce qui est visible dans le PDF/screenshot annoté qu'il envoie, hors zones coloriées en jaune**. Le jaune = à dégager. Ce qu'il a croppé (pas visible) = ne doit pas être là.

Pour les pages **secteur** Neocell, ça donne :
- GARDER : hero (badge "Secteur X" + titre + texte + boutons "Réserver un audit"/"Calculer mon ROI"), les 4 stats, "Les défis" (4 cartes), "Nos solutions" (les 3 agents), **ET le CTA final "Prêt à transformer…"** (titre + sous-texte + bouton "Réserver mon audit gratuit" + "Garantie ROI x3"). Le bouton d'appel à l'action se garde — validé explicitement.
- DÉGAGER : le **header** entier (croppé dans son PDF), le **footer** (jaune), la section **"Découvrez aussi"** + tout ce qui suit, le widget calendrier `div.nb-widget` (overlay "Bloquer un créneau"), et le **fil d'ariane "Accueil / Secteurs / …"** (nav en haut du hero) — validé explicitement.

`trim-page.js` supprime aussi : le **bandeau newsletter** `#newsletter-topbar` et le **bandeau cookies** `#cookie-banner`. Et il rend **tous les liens/boutons inactifs** (retire `href`, ajoute `pointer-events:none` sur `<a>` ; `disabled`+`pointer-events:none` sur `<button>`), SAUF la barre `← Références` qui reste cliquable (retour hub). Aspect visuel inchangé, clic sans effet.

`trim-page.js` (récap complet) : supprime `<header>`, `<footer>`, `#newsletter-topbar`, `#cookie-banner`, `.nb-widget`, le `<nav>` fil d'ariane (`^Accueil / <mot> /` — 2e segment variable : Secteurs/Entreprises/Cas d'usage), et dès qu'une `<section>` matche `D[ée]couvrez aussi` (accent optionnel) la supprime elle + toutes les suivantes (CTA "Prêt à…" conservé). Puis neutralise liens/boutons. Le hero commence direct au badge "Secteur/Cas d'usage X".
