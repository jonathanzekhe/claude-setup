**Catégorie officielle (visible ICP, validée 2026-05-27)** : **"Solutions IA opérationnelles pour entreprises"**

**Why:** L'ICP (dirigeants PME/COO/fondateurs suisses+français) ne tape pas "agentique" sur Google — c'est encore jargon industrie (a16z, Anthropic). Ils tapent "agents IA entreprise", "automatisation PME", "IA pour entreprises". Priorité à la lisibilité immédiate. "Opérationnel" est le différenciateur vs "innovant" générique (Naiom) — il dit que les agents OPÈRENT, pas juste qu'ils existent.

**Réserve future** : "Solutions agentiques" gardé dans `<meta name="keywords">` (invisible utilisateur, indexation Google). Si dans 6-12 mois "agentique" percole dans l'ICP, on est déjà positionné dessus sans coût visible. À ré-évaluer Q4 2026.

**Différenciateur clé à communiquer** : on ne fait pas de l'automatisation no-code Zapier/Make générique → **"des agents opérationnels qui prennent en charge les processus de l'entreprise"**. Le mot "automatisation" reste utile (familier, SEO) mais doit être qualifié par "agents opérationnels".

**Vocabulaire visible (ICP-first)** :
- Solutions IA opérationnelles (catégorie officielle)
- Agents IA opérationnels (le mot "opérationnel" = la force)
- Entreprise(s) (jamais "business" — Suisse + sérieux)
- Automatiser leurs opérations (action ICP comprend)
- Sur mesure (vs clé-en-main générique)
- Infrastructure IA qui vous appartient (différenciateur propriété vs SaaS locked-in)

**Vocabulaire réservé (keywords meta uniquement, pas dans titres/desc visibles)** :
- Solutions agentiques, agentique entreprise → pari long terme, à hisser quand le marché ICP aura adopté le mot

**OG image direction validée (2026-05-27)** : variante C — **dark minimaliste** (fond noir profond, titre serif cream avec "opérationnelles" en orange #E26137, petite icône + wordmark en haut à gauche). Choisie sur 3 variantes A/B/C présentées via `og-variants.html`. Trade-off accepté : projette "haut de gamme" même si positionnement est "opérationnel pour entreprises".

**Pattern bust cache socials** : à chaque change majeur d'OG image, bumper le query param dans `og:image` et `twitter:image` (ex: `og-image.jpg?v=c1` → `?v=c2`). Sans ça, Telegram/LinkedIn/Facebook continuent à servir l'ancienne image de leur cache pendant des jours/semaines.

**Vocabulaire interdit** :
- "business" → entreprise
- "studio" → agence / équipe (cf feedback_vividflow_not_a_studio)
- "lite" / "basique" / "découverte" → cadrer par stade

**How to apply:**
- Toute meta tag (title, description, og:*, twitter:*) : mettre "solutions agentiques" et "entreprises" en premier plan
- Hero/H1 on-site : OK de garder "agents IA" (opérationnel, parlé) tant que la meta hisse "solutions agentiques"
- Description SEO type **validée** (live sur vividflow.co, scellée par Jonathan le 2026-05-27) : *"VividFlow aide les entreprises à automatiser leurs opérations grâce à des agents opérationnels sur mesure."*
- Structure : `[Brand] aide [cible] à [action] grâce à [moyen]` — calque la formule Naiom validée par Jonathan ("Naiom aide les PME à automatiser leurs opérations grâce à des agents IA clé en main"). Une seule direction par phrase, jamais d'empilage. Si tentation de mettre plus d'une force : couper.
