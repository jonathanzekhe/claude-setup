**P6 — Ce n'est pas un chatbot**
Copy slide : « Ce n'est pas une IA qui répond. / C'est une IA qui travaille avec votre entreprise. »
Oral : Un chatbot répond à une question. C'est utile, mais ça reste limité. Dans une entreprise, il faut plus que répondre. Il faut comprendre les règles, utiliser les bons outils, suivre les décisions, garder le contexte, et savoir quand remonter à une personne. C'est là qu'on sort du simple chatbot.
Intention : éduquer sans jargon. Différence IA conversationnelle vs IA opérationnelle. Pas de critique de ChatGPT/Claude, simplement pas le même niveau.

**P7 — Un corps vivant** (VALIDÉ v5)
Copy d'esprit validé (wording exact à polir, idée intouchable) : « Un système agentique fonctionne comme un corps vivant. / Il ne repose pas sur des agents isolés. / Il repose sur une infrastructure. »
Objectif : comprendre en 10 s qu'un vrai système agentique n'est pas un agent isolé mais une infrastructure complète où plusieurs fonctions travaillent ensemble. Ressenti = "ce n'est pas juste un agent IA, c'est une organisation vivante autour de mon entreprise."
Composition validée : GAUCHE = silhouette / corps vivant humain stylisé, sobre, premium (représente l'organisation vivante du système, PAS un robot IA). DROITE = les composants, chacun avec son rôle simple.
Les 7 composants : 1) Cerveau/tête = bras droit opérationnel (coordonne, priorise, orchestre, sécurise, remonte les bonnes décisions). 2) Yeux/oreilles = capteurs (lisent demandes, mails, CRM, documents, messages, signaux entrants). 3) Cœur = mémoire agentique (contexte, règles, historique, priorités, décisions, validations). 4) Bras = agents spécialisés (recherchent, préparent, relancent, contrôlent, suivent, reportent). 5) Mains = actions dans les outils (CRM, email, agenda, fichiers, logiciels métiers, documents). 6) Système nerveux/squelette = workflows & circulation (structure comment info et actions circulent entre outils, agents, humains). 7) Humain/dirigeant = validation & arbitrage (garde le contrôle, valide les décisions importantes, arbitre).
Interdits : schéma technique, illustration enfantine, robot, imagerie médicale, science-fiction, cerveau lumineux, "plateforme" comme concept central, réduction à "tête/bras/cœur". Montrer que toutes les parties travaillent ensemble.
Ressenti attendu : sobre, clair, premium, vivant — infrastructure intelligente mais humaine et contrôlée.
