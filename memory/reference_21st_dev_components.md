URL : https://21st.dev/community/components

Usage obligatoire :
- Avant toute creation de composant UI (mockup HTML ou app Brvndlab)
- Pendant le design d'une section, page ou interaction
- Meme pour le developpement du SaaS Brvndlab/VividFlow, pas uniquement pour les mockups

Pourquoi : 21st.dev agrege des composants React premium faits par la communaute, souvent avec Motion/Framer Motion integre. C'est une source de patterns UX et d'inspirations visuelles concretes (pas juste theoriques).

Comment l'utiliser :
1. Identifier le type de composant recherche (hero, pricing, testimonials, card, nav, etc.)
2. Aller chercher sur 21st.dev/community/components avant de partir sur une implementation generique
3. S'en inspirer OU adapter au design system Brvndlab (old money premium, noir profond, accents champagne, typo light)
4. Croiser avec les autres inspirations deja enregistrees (Scale20, Jens Heitmann Apify, heyDominik)

A combiner avec :
- shadcn/ui pour les primitives
- Motion (framer-motion v12) deja installe dans brvndlab-app
- Les inspirations deja enregistrees dans reference_brvndlab_inspirations.md
