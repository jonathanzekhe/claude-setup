**Thème (90% du travail)** : big idea = le mécanisme révélé (frein n°1, profil, score, plan d'action perso). Vendre une TRANSFORMATION, pas une information. 3-5 thèmes selon niveau d'awareness, à tester (organique d'abord, ads ensuite). Cible mature : dire "diagnostic"/"audit", pas "quiz" (critique Max Piccinini). LP : logo/branding, phrase curiosité, promesse spécifique + durée ("2 minutes"), CTA qui promet le résultat (jamais "commencer le quiz"), track record + stats, social proof, disclaimer Meta. Tester avec LP vs sans LP (1er A/B).

**Questions : 12-14 (jamais <7)**. Ses chiffres varient (7-12 module, 13-14+ structure, 17-20 erreurs) mais consensus : <7 = zéro valeur perçue du résultat ; pic d'abandon vers Q12-13 SAUF format score (quiz Excel 17-20Q, 52% optin). Bonne friction : qui abandonne n'a pas un problème assez fort. 5 types DANS L'ORDRE :
1. Engagement (2-3) : ice breakers zéro réflexion.
2. Situation (jusqu'à 7) : état actuel + objectif, AUTO-ÉTIQUETAGE (le prospect se dévoile en cliquant), segmente les profils.
3. Pain deepen (5-6) : symptômes, tentatives échouées, durée ; le prospect AVOUE le problème lui-même.
4. Implication/coût (3-4) : "échelle 1-5, à quel point cette phrase te parle" ; le problème devient urgent.
5. Commitment (2-3) : projection, échéance, "Ton résultat est prêt. Es-tu prêt à le recevoir ?".
Règles dures : 1 question = 1 question ; 2-4 réponses (max 5-6, réservé segmentation) ; langage enfant de 8-10 ans ; progress bar OBLIGATOIRE ; bouton retour OBLIGATOIRE ; questions fermées uniquement (jamais d'ouvertes dans le quiz). Questions bonus (curiosité, n'impactent pas le résultat) pour enrichir l'avatar client. PAS de questions de qualification sèches dans le quiz (erreur n°2) : elles vont dans iClosed.

**Pages de réassurance** (le différenciateur que 95% n'ont pas) : écrans intercalés liés à la question d'avant, UNE fonction par page : casser croyance/objection OU social proof/désir OU rassurer OU coût de l'inaction OU recapturer l'attention. Courtes, visuelles, personnalisées.

**Optin : À LA FIN, jamais au début** (erreur n°4). Précédé d'une waiting page (récupération → analyse → recherche). Progress bar PAS terminée sur l'optin (tension). Abandon optin ~10-12%. "Tu reçois ton résultat par mail" = vraies infos. Case RGPD.

**Page de résultat (≥10% bookent, 13-15% chez ses clients)** : Félicitations {prénom} + "toutes tes réponses ont été prises en compte" + résultat personnalisé + mini VSL 5-10 min PAR PROFIL (3 profils = 3 VSL, jamais générique ; écrit en complément) + bénéfices + social proof + comment ça marche (étapes) + à propos + CTA. Calendrier iClosed EMBEDDÉ direct (pas de bouton).

**Qualification (dans iClosed, pas le quiz)** : cible (métier), décisionnaire, "si la solution résout ton problème, prêt à investir ?" + liens (site, profil). Créneaux 72h MAX (anti no-show). Page de remerciement : vidéo 2-3 min (féliciter + conditions + étapes), témoignages, renvoi vers ressources (règle des 4h de contenu consommé avant achat), lien WhatsApp "clique ici pour recevoir un cadeau" = le prospect écrit en premier au setter. Setter sur tout optin non booké (force d'iClosed : data des non-bookés).

**Emails : 1 séquence PAR profil, 7 emails** : 0 envoi du résultat ; 1 identification/teaser du problème ; 2 acter le problème ; 3 book call (déculpabilisation) ; 4 pourquoi nous + social proof ; 5 objections ; 6 balle dans ton camp. Puis newsletter.

**KPI** : démarrage quiz ≥35-40% (50% = très bien, <30% = revoir ads/LP) ; optin B2B ≥13-17% (B2C ≥20%) ; résultat→call ≥10% ; A/B permanent. Les ADS restent déterminantes : un quiz ne sauve pas des mauvaises ads.

**RÈGLES DE COPY JONATHAN (feedback 21/08 sur la v1 des questions)** :
- **Les questions signalent ton niveau.** Une échelle de CA qui plafonne à "50k+" fait fuir ceux qui font 100-300k ("c'est des petits qui cherchent"). Toujours faire monter les échelles au-dessus du réel des plus gros profils visés (jusqu'à 100k+/mois), premier palier "Moins de 10k" (pas "5-10k"). Le filtre reste réel mais invisible.
- **ICP matrixé make money : questions CASH-FIRST, jamais time-first.** Ils bookent avec celui qui peut leur faire faire plus de cash ; le temps est une conséquence révélée dans le diagnostic, pas la promesse des questions. Bannir les formulations "récupérer du temps / te libérer" dans les questions.
- **Registre premium, pas cheap.** Tutoiement OK mais bannir le "langage petit" dans les options ("dans ma tête", "tableur que je suis seul à comprendre") : registre décisionnaire ("Tu prends tes décisions business sur quoi ?").
- **Questions validées par capture (à reprendre telles quelles)** : "Combien y a-t-il de personnes dans ton équipe opérationnelle ?" (Je travaille seul(e) / 2 à 5 / 6 à 10 / 11 à 20) et "Quel est le principal défi que tu rencontres pour scaler à +50k€/mois ?" (Acquisition client / Vente / Délivrabilité des clients / Déléguer-recrutement), cette dernière ADAPTATIVE selon le CA (50-100k → "passer les 100k" ; 100k+ → "aller chercher les 300k") : ne jamais afficher un objectif inférieur au réel du prospect.

**RÈGLE DE FORME (21/08)** : toutes les questions en forme interrogative COMPLÈTE et propre ("Quel est ton business ?", "Combien y a-t-il de personnes dans ton équipe opérationnelle ?", "À quel point cette phrase te correspond-elle ?"). JAMAIS de tournures parlées type "Ton business, c'est quoi ?" : Jonathan trouve ça anormal et cheap. Tutoiement oui, relâchement non.

**Corrections v3 (21/08, Jonathan)** : objectifs sur 6 mois, jamais 12 ; question pilotage des chiffres = inclure l'option humaine ("Mon équipe me fait des reportings réguliers"), "à l'instinct" pas "au feeling" ; ajouter "Du vibe coding" dans les investissements déjà tentés ; échelles = forme unique "À quel point cette phrase te correspond ?" ; dire "je suis encore trop dans l'opérationnel", jamais "tout repose sur moi" ; question d'engagement final = JAMAIS d'options temporelles molles ("ce trimestre", "plus tard") → échelle de détermination 1-5 ("Je me renseigne" → "Déterminé, je veux avancer vite").
