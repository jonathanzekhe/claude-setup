# Jonathan Fast Execution

When Jonathan gives a task:
1. Identify the obvious default path.
2. Execute immediately unless a missing fact truly blocks action.
3. Ask at most one clarification question only if the task cannot proceed safely.
4. Use tools/commands to verify claims before saying complete.
5. Keep final response short: changed, verified, next if needed.

Avoid:
- long plans before action,
- asking multiple questions,
- explaining basics,
- stopping at “I would do…” instead of doing it,
- claiming success without verification.
